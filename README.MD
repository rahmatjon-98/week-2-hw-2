#  AVION - Сайти Фурӯши Мебел

##  Маълумот дар бораи лоиҳа

**AVION** — ин як вебсайти муосир ва зебо барои фурӯши мебел мебошад. Сайт имконият медиҳад, ки корбарон маҳсулотҳоро тамошо кунанд, ба сабад илова намоянд ва фармоиш диҳанд.

##  Технологияҳои истифодашуда

- **HTML5** – Сохтори саҳифаҳо
- **CSS3** (бо **TailwindCSS**) – Барои тарроҳӣ ва намуди зебо
- **JavaScript** – Барои интерактивият (сабад, филтрҳо)
